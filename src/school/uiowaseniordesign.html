    • ECE:4880/4890 Senior Design Project
    Our project is a modification of an existing open-source development board powered by the Kria K26 SOM.
    The goal of this project is to create a semi-portable, low-cost, low-power, and flexible platform for sending high resolution stereoscopic video over a WiFi 7 network connection.
    Our main priority wasn't to create a fully functional product, but to create a platform that could be easily modified by future students/design groups.

    My role in this project was to complete the PCB layout of the board and to research and implement an existing WiFi 7 module.
